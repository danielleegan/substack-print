FAQs:

My newspaper works on the web, but when I try to print/save, the output gets messed up. What gives?

If you’re using Safari, make sure that the option to “print headers and footers” is NOT checked. If that still doesn’t work, switch to Chrome. Unfortunately Safari overrides print settings sometimes, there isn’t anything I can do about it :(

How do I save as a PDF?

In the print menu!
On Chrome, within Destination, select “Save as PDF.”
On Safari, there is a button that says “PDF” in the bottom left corner.

Will you be adding more features/formats?

Maybe! If I have the time :)

I’m a paid subscriber to someone, why can’t I print their paywalled articles?

I can only pull what’s publicly available online. Only Substack HQ can show you what’s past the paywalls.

What are some ways I should use the Substack Print?

See inspiration in the Substack Print Guide!

Why isn’t the article link I pasted working?

Make sure it’s in this format: publicationname.substack.com/p/articlename
You can get this from the direct URL (what shows in the bar at the top of the page).
